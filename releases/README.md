# Releases

Field-test APKs ship via **GitHub Releases** (tag `v*` → CI builds + attaches),
not from this folder. `sih26168-debug.apk` below is the last hand-built artifact
and will be removed from git once the first CI Release exists (see
`.github/workflows/release.yml`).

- Latest release: https://github.com/Himanshu121865/sih26168/releases/latest
- Cut one: `git tag v0.1.0 && git push origin v0.1.0` (add a CHANGELOG entry first)
